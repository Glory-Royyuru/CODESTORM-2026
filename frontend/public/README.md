# `public/` — static files

Files here are served as-is from the site root (for example `public/next.svg` → `/next.svg`).

The SVGs currently here (`file.svg`, `globe.svg`, `next.svg`, `vercel.svg`, `window.svg`) are leftovers from `create-next-app`. **The app doesn't use any of them**: the logo and GitHub icons are inline SVGs in `src/components/hero/icons.tsx`, and all other icons come from `lucide-react`. They can be deleted safely.
